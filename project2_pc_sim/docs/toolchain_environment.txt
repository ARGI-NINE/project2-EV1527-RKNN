Project2 PC Simulator portable environment reference
====================================================

Purpose
-------
This file records requirements and variables, not one developer's absolute paths
or a claim that every machine has already been validated.

Required for C gateway/tests
----------------------------
- CMake >= 3.15
- C11 compiler and a matching CMake generator
- CTest (provided by CMake)
- A shell capable of piping binary stdout when running replay manually

Required for Qt GUI
-------------------
- C++17 compiler compatible with the selected Qt build
- Qt 5 components: Core, Gui, Widgets, Network
- On Windows, use one compiler family consistently. For example, a MinGW Qt
  package must be used with the matching MinGW compiler, not MSVC.
- Make Qt discoverable with one of:
    CMAKE_PREFIX_PATH=<qt-prefix>
    Qt5_DIR=<qt-prefix>/lib/cmake/Qt5

Required for Python RF tools
----------------------------
- Python 3
- Dependencies imported by the repository's WAV decoder/extractor
- Keep the virtual environment outside versioned source semantics; .venv,
  __pycache__, sim_data, and runtime outputs are generated content.

Required for WSL vision bridge
------------------------------
- Python 3 in WSL
- OpenCV (cv2) and the dependencies imported by vision/rknn_pipeline.py
- An explicit readable --source
- An ONNX model supplied with --model, or the repository-root default asset
- A TCP address/port reachable from Windows; bridge default is 127.0.0.1:17655
  while the Qt GUI default vision port is 0 (disabled).

Portable configure examples
---------------------------
Protocol/gateway only:
  cmake -S project2_pc_sim -B build/pc \
    -DBUILD_LINUX_APP=ON -DBUILD_QT5_GUI=OFF -DBUILD_TESTING=ON

Qt enabled:
  cmake -S project2_pc_sim -B build/pc-gui \
    -DBUILD_LINUX_APP=ON -DBUILD_QT5_GUI=ON -DBUILD_TESTING=ON \
    -DCMAKE_PREFIX_PATH=<qt-prefix>

Then:
  cmake --build build/pc-gui
  ctest --test-dir build/pc-gui --output-on-failure

Environment capture before reporting a result
---------------------------------------------
Record these from the machine that performed the run:
- cmake --version
- compiler --version
- python --version
- qmake --version or the resolved Qt5_DIR
- generator and architecture
- WSL distribution/version when the bridge is used
- exact commands, exit codes, test counts, and skipped hardware/model checks

Do not copy a historical local path into canonical instructions. Do not describe
a configuration as validated unless the listed command was actually executed on
that environment. See ../README.md for run and acceptance steps.
